# AiR Plain-Language Review

## Acceptance criteria

The learner-facing curriculum was reviewed against a simple standard for learners beginning at age eight. Each lesson begins with a familiar object, situation, or story; introduces one primary idea; limits checkpoint prompts to one decision; provides a worked action; and ends with a visible next move. Core summaries remain short, and unexplained specialist terms are excluded from the required learning path.

| Check | Result |
|---|---|
| One central idea per lesson | Passed across all 12 lessons |
| Concrete opening analogy | Passed across all 12 lessons |
| Summary of 24 words or fewer | Enforced by automated test |
| Checkpoint prompt of 32 words or fewer | Enforced by automated test |
| No prerequisite technical vocabulary | Passed; specialist-jargon exclusions are tested |
| One action, one example, one reflection, one next move | Passed through the five-checkpoint lesson structure |
| Read-aloud and no-device path | Covered in the trainer handbook |
| Optional depth without age ranking | Explore, Create, and Build are available in every lesson |

This review establishes a design and editorial baseline rather than a clinical reading-age certification. Facilitators should continue observing real learners, recording confusion points, and improving examples without weakening the underlying idea.

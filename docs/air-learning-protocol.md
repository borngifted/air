# The AiR Learning Protocol (superseded)

**Superseded on 2026-09-15 by [AiR: Flow With AI](air-flow-with-ai.md).** The program's source of truth is now the one-hour class built on the four moves (Clear, Direct, Judge, Make), the Prompt Relay competition, scoring, and the real-life connection. Where anything here disagrees with that document, that document wins.

What survives from this protocol:

- The activities (three stations, the walls, controlled confusion, impossible instructions, AI cannot answer, collision) stay on the site at `/situations` as **optional facilitator warm-ups**. A facilitator may open a session with one before the one-hour class. They are not the method.
- The evidence table (first action, first AI request, abandoned attempts, tool switching, questions asked, what they save, final decision, second attempt) is useful for facilitators watching a Prompt Relay. It is not a grade; scoring uses the 30-point rubric.
- The facilitator handbook `environment-designer-training.md` is kept for the warm-ups only.

The original protocol text ("don't explain AI", six actions Expose → Disrupt → Explore → Collide → Reflect → Evolve) is retired. AiR now explains the mission, names the four moves, and runs the competition.

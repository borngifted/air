# AiR Brand and Commercial Production Package

**Prepared for AiR — AI Readiness and Digi2U.org**  
**Version 1.0 · September 2026**

This delivery package contains two working documents:

| File | Use |
|---|---|
| `AiR-Brand-Kit.md` | The source of truth for positioning, messaging, voice, logo, color, typography, photography, motion, accessibility, campaign structure, and ready-to-use copy |
| `AiR-Commercial-Shoot-Book.md` | The production plan for four 30-second commercials—Clear, Direct, Judge, and Make—with timed visual beats, full scripts, 15-second cutdowns, 6-second bumpers, casting, camera, sound, props, wardrobe, schedule, and post-production guidance |

Start with the **Brand Kit** to align the creative team. Then use the **Commercial Shoot Book** for casting, budgeting, pre-production, rehearsals, shooting, and post-production.

The referenced AiR logo and campaign visuals are hosted on the live site at [borngifted.github.io/air/](https://borngifted.github.io/air/). The official source repository is [github.com/borngifted/air](https://github.com/borngifted/air).
